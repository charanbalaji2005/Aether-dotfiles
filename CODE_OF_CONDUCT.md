# Code of Conduct

## The short version

Be respectful. Disagree about code, not people. No harassment, no personal attacks, no bigotry.

## Expected behavior

- Give constructive, specific feedback ("this breaks on multi-monitor because X" beats "this is
  bad").
- Assume good faith — most bugs are mistakes, not malice.
- Respect that contributors have different experience levels with Hyprland, QML, and Linux
  generally.

## Unacceptable behavior

- Harassment, insults, or discriminatory language directed at people.
- Publishing others' private information without consent.
- Sustained disruption of discussions or reviews.

## Enforcement

Maintainers may remove comments, close PRs/issues, or block contributors who violate this. Report
concerns the same way you'd report a security issue (see `SECURITY.md`) if you'd rather not raise
it publicly.

## Scope

Applies to this repo's issues, pull requests, discussions, and any other official project spaces.
