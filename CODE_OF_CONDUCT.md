# Code of Conduct

AetherOS adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and focus on the work. Harassment,
personal attacks and discriminatory language aren't accepted in issues, pull requests or any
project space. Maintainers may edit or remove contributions and restrict participation to keep
the project welcoming.

Report concerns privately to the maintainers through the contact listed on the repository
profile (or a private security advisory if a public issue isn't appropriate). Reports are kept
confidential.
